# Speed Test Downloading

Консольный скрипт на TypeScript для замера скорости скачивания по заданному URL. Он выполняет 10 последовательных GET-запросов и запускает следующий запрос после полного чтения предыдущего ответа. Тело ответа читается порциями.

## Запуск

Понадобится Node.js 22.14 или новее с npm. Устанавливать зависимости не нужно.

Из корня проекта выполни команду, подставив прямой HTTP- или HTTPS-адрес файла.

```powershell
npm start -- "<прямой URL файла>"
```

Используй конечный URL, который возвращает статус HTTP 2xx. Оставь URL в кавычках, если в адресе есть параметры запроса.

## Настройки

Для запуска без аргументов создай файл `.env` в корне проекта и подставь свой URL.

```dotenv
DOWNLOAD_URL="<прямой URL файла>"
DOWNLOAD_TIMEOUT_MS=60000
```

Запусти `npm start`. URL из аргумента командной строки имеет приоритет над `DOWNLOAD_URL`.

Параметр `DOWNLOAD_TIMEOUT_MS` задаёт лимит на каждый запрос в миллисекундах, включая чтение тела ответа. По умолчанию действует лимит в 60 секунд.

## Результат

- **Среднее время запроса** — сумма длительностей десяти запросов, делённая на 10. Время каждого запроса включает ожидание ответа и скачивание.
- **Общий объём** — сумма размеров тел ответов в байтах.
- **Скорость** — общий объём в мегабайтах, делённый на суммарное время в секундах. Один мегабайт равен 1 000 000 байт.

**Пример вывода**

```text
Среднее время запроса: 125.00 мс
Общий объём: 5000000 байт
Скорость скачивания: 4.00 МБ/с
```

При ошибке скачивания скрипт сообщает номер запроса и завершает работу с кодом `1`.

## Тест

Задай `DOWNLOAD_URL` в `.env` или в окружении и запусти тест из корня проекта.

```powershell
npm test
```

Тест один раз скачивает файл по этому адресу и проверяет, что ответ получен целиком, содержит данные, а время скачивания положительное. Для запуска нужен доступ к заданному адресу.
